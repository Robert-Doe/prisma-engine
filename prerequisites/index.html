Before any module's tutorial teaches you to build something, it assumes you already have these nine ideas in hand. Rather than re-explain them every time (which is how tutorials rot — the fifth explanation of "what's a DOI" is never as good as the first), every module links back to the specific primitives it needs from here, tag-style, and moves on.

Read what's relevant to the module you're about to start. You don't need all nine before Module 1 — just the ones that module tags.
