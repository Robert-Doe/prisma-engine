Module 24 — Track 2: Applied LayerQualitative Evidence Synthesis (Meta-Ethnography)

Depends on Track 1: Module 15

00Before You Start

Finished Module 15 and read Module 0's Meta-Ethnography concept page — this module implements the "translation" step that page describes.

This module's own demo contains a real mistake, on purpose. Its first run genuinely misclassified two agreeing excerpts as contradictory. Rather than quietly rewrite the example text to hide it, the demo keeps it and explains exactly why it happened — see Section 04 and the Brain Exercise.

01The Big Analogy

Two travelers, two languages, one translator Two travelers describe the same city to a translator — one in French, one in Japanese. The translator's job isn't just converting words; it's figuring out whether the two travelers are actually saying the same thing (reciprocal), flatly disagreeing (refutational), or each describing one half of a bigger picture neither alone captured (line-of-argument). A careless translator who only checks for the presence of a negation word in each sentence — instead of what that negation actually means in context — will sometimes get it wrong. This module's translator does exactly that, and its own demo catches it doing so.

02What Happens, Step by Step

  1. Each study's raw excerpts are coded independently via Module 15's real, unmodified open_code()
  2. translate_studies() groups every excerpt by open code across all studies, then compares every pair of studies sharing a code
  3. A simple negation-marker check decides reciprocal (both excerpts negated the same way, or neither is) vs. refutational (one is negated, one isn't)
  4. Module 15's axial_code() groups all studies' excerpts into themes, exactly as before
  5. line_of_argument() combines two non-empty themes by name into one new templated sentence — demonstrating the shape of meta-ethnography's most interpretive step, not performing real interpretation

04The Code, Explained

_NEGATION_MARKERS = ("not ", "n't", "never", "no longer", "actually less", "actually worse")

def _is_negated(text: str) -> bool:
    lowered = text.lower()
    return any(marker in lowered for marker in _NEGATION_MARKERS)

This function cannot tell "I don't talk to anyone" (negation describing a state of isolation) from "I don't think that's true" (negation of a claim) — both contain "n't", and the check has no way to look past the literal marker to what it's actually doing in the sentence. That gap is exactly what produced the real misclassification above.

05Limits / What You Cannot Do Yet

Can't do yet

  • Reliably tell "negation describing a phenomenon" from "negation of a claim" — a real, demonstrated failure mode, not hypothetical
  • Perform genuine line-of-argument reasoning — line_of_argument() names two themes and asserts a connection by template, it doesn't discover one
  • Handle more than a pairwise comparison per code — three-plus-study agreement/disagreement patterns aren't classified as a group

Can do

  • Correctly classify a genuine disagreement between two studies' findings on the same code
  • Make its own classification mistakes visible and explainable rather than silently wrong
  • Demonstrate the real, three-part structure of meta-ethnography's translation process

07Brain Exercise

Why does this tutorial keep the misclassified social_isolation example instead of quietly editing the excerpt text so both results come out correct?
Because editing it away would delete the single most honest piece of evidence this module can offer: a real, first-run demonstration of exactly why simple keyword heuristics are risky for qualitative judgment calls. If this tutorial only showed the correct fewer_interruptions classification, a reader could walk away believing the negation heuristic is reliable — a false impression this course's quality bar exists to prevent. Keeping the mistake, and explaining it precisely, teaches the actual lesson: automated heuristics can get qualitative nuance wrong in specific, understandable ways, which is exactly why real meta-ethnography is done by trained researchers, not scripts.

08There Are No Dumb Questions

Could the negation heuristic be fixed to avoid this specific mistake?
Partially — you could special-case phrases like "don't talk to," "don't see," "don't interact with" as describing isolation rather than negating a claim. But that would just move the same underlying problem to different phrasing ("I barely speak to anyone" has no negation marker at all, and would be misclassified the other way). This is a real, open problem in automated sentiment/stance detection, not something a short keyword list can fully solve.
Is `line_of_argument()`'s output actually meta-ethnography, or just a sentence template?
Structurally it's a template — see DECISIONS.md. Real line-of-argument synthesis requires a human researcher to notice a genuinely new connection between themes that neither theme states alone, which is a real act of interpretation this function doesn't perform. What it demonstrates is the shape that step's output takes, not a claim that real synthesis happened automatically.
Why compare studies pairwise instead of all at once?
Simplicity, and it matches how Noblit & Hare originally described the process — translating studies into each other's terms one relationship at a time. A three-or-more-study group classification (do all five studies broadly agree, or is there a majority-vs-minority split?) is a real, harder problem this module doesn't attempt.
