Module 15 — Track 1: Core EngineThematic Coding Engine

00Before You Start

No new prerequisite page — this module is the mechanical version of the same instinct behind Synthesis vs. Summary: organizing by idea instead of by source, just applied to qualitative excerpts instead of whole papers.

01The Big Analogy

Sticky notes on a wall A researcher reads through interview transcripts and slaps a sticky note with a short label on every interesting bit — "feels disconnected," "gets more done," one note per idea, as they go. That's open coding: bottom-up, one excerpt at a time, no predetermined categories. Later, they stand back from the wall and start physically clustering sticky notes that seem to be circling the same underlying idea into groups — "these five are all really about social connection," "these three are all about how the workday itself changed." That's axial coding: relating the codes you already have to each other.

open_code() is the sticky-note-writing pass. axial_code() is standing back and clustering the wall. Neither step invents structure that wasn't in the data — both just make the structure visible and checkable.

02What Happens, Step by Step

  1. open_code() checks each excerpt against every code's trigger phrases — an excerpt can match zero, one, or several codes
  2. Each excerpt becomes a CodedExcerpt, carrying whichever codes actually matched
  3. axial_code() groups excerpts by theme, based on THEME_GROUPINGS mapping each theme to the set of open codes that belong to it
  4. An excerpt whose codes span two themes appears under both — nothing forces a false single categorization
  5. An excerpt matching no code at all appears in neither theme, reported separately as genuinely off-topic

04The Code, Explained

def open_code(excerpts, coding_rules):
    coded = []
    for study_title, text in excerpts:
        lowered = text.lower()
        codes = [code for code, triggers in coding_rules.items()
                 if any(t in lowered for t in triggers)]
        coded.append(CodedExcerpt(study_title=study_title, excerpt=text, codes=codes))
    return coded

def axial_code(coded_excerpts, theme_groupings):
    themed = {theme: [] for theme in theme_groupings}
    for excerpt in coded_excerpts:
        for theme, member_codes in theme_groupings.items():
            if member_codes & set(excerpt.codes):     # set intersection
                themed[theme].append(excerpt)
    return themed

The set intersection (member_codes & set(excerpt.codes)) is what lets one excerpt land in more than one theme — there's no break or early return stopping the loop once one theme matches.

05Limits / What You Cannot Do Yet

Can't do yet

  • Discover codes automatically from unlabeled text — trigger phrases have to be written by a human first
  • Handle negation ("I don't feel isolated at all" would still trigger on "isolat")
  • Produce a written synthesis — this module organizes excerpts into themes, it doesn't write the prose that interprets them (that's closer to Module 24)

Can do

  • Apply a coding scheme identically and repeatably across any number of excerpts
  • Represent an excerpt under multiple themes when it genuinely belongs to more than one
  • Correctly leave an off-topic excerpt out of every theme, rather than forcing it somewhere

07Brain Exercise

Why does `axial_code()` loop through every theme for every excerpt instead of stopping at the first matching theme?
Because stopping early would silently throw away real information whenever an excerpt's codes span more than one theme — exactly the "S5" case in the self-checks, which genuinely discusses both disrupted social connection and blurred boundaries in the same sentence. A qualitative excerpt reflecting two real, distinct ideas at once is common, not an edge case to suppress. The set intersection check runs for every theme specifically so that reality gets represented instead of forced into a false single bucket.

08There Are No Dumb Questions

Isn't keyword matching a pretty crude way to do something as nuanced as qualitative coding?
Yes, genuinely — see the Limits section's negation example. Real qualitative coding is done by trained humans, often two independently reconciling disagreements, precisely because it requires judgment a keyword rule can't replicate. This module proves the structure of the process (bottom-up codes, then higher-level grouping) is mechanical and repeatable — it doesn't claim the specific code assignments are as trustworthy as a real researcher's.
What would happen if two themes in `THEME_GROUPINGS` shared an open code?
Any excerpt carrying that code would appear under both themes — the set-intersection check has no concept of themes being mutually exclusive. That's not a bug; a code genuinely belonging to two real themes is a legitimate coding-scheme design choice, not an error state.
How is this different from Module 10's extraction schema?
Module 10 validates that a fixed, predetermined set of fields got filled in correctly for a study with quantitative data — closed-ended, always the same slots. This module discovers which codes apply to a given excerpt from an open-ended set — an excerpt might match three codes, one, or none, which isn't how a validated form works at all.
